# Apex Inventory — DevOps Repository

This repository contains all Infrastructure as Code (**Terraform**), Server & Kubernetes Configuration (**Ansible**), Kubernetes Application Packaging (**Helm**), and **CI/CD** pipelines for **Apex Inventory**.

## Mandatory Reading Before You Start

1. **[DEVOPS_HANDBOOK_ALL_IN_ONE.md](./DEVOPS_HANDBOOK_ALL_IN_ONE.md)** — Complete architecture, folder layout, security group matrix, tool boundaries, and AI prompt template.
2. **[AI_ACTIVITY_AUDIT_LOG.md](./AI_ACTIVITY_AUDIT_LOG.md)** — **Mandatory:** Every engineer and AI assistant must log every edit, command, and verification output here.
3. **[DEVOPS_COLLABORATION.md](./DEVOPS_COLLABORATION.md)** — Active task claims and completed milestones.
4. **[handoffs/README.md](./handoffs/README.md)** — Instructions and template for creating your `handoffs/<your-name>/<service>/HANDOFF_REPORT.md` when you finish a service.
